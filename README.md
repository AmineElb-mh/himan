# HIMAN KEBAB website

React + Vite one-pager met animaties via [Motion](https://motion.dev) (`motion/react`).

```bash
npm install
npm run dev      # lokaal ontwikkelen
npm run build    # productieversie in dist/
```

## Inhoud aanpassen
- Gegevens, uren, telefoon, logo: `src/data/site.js`
- Menu (gerechten, prijzen, foto's): `src/data/menu.js`
- Google-reviews: `src/data/reviews.js`
- Foto's: `public/assets/images/` (zie LEESMIJ.txt daar)
- SEO en JSON-LD: `index.html`
- Kleuren: CSS-variabelen bovenaan `src/styles.css`
